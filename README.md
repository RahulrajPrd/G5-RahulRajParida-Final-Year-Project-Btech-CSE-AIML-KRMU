
## Setup
1. **Clone the Repository**:
   - Use GitHub Desktop to clone this repo, or download it as a ZIP from GitHub.
2. **Install Dependencies**:
   - Install Python 3.x.
   - Run `pip install -r requirements.txt` in a terminal, or manually install the libraries listed in `requirements.txt`.
3. **Download the Dataset**:
   - The dataset is too large for GitHub. Download it from [Google Drive link] (replace with your link) and place it in the `data/` folder.

## Usage
1. **Train the Model**:
   - Open `GAN_Training_California/Gurugram` and run it in your Python environment (e.g., VS Code, Jupyter Notebook, or Google Colab).
2. **Generate Layouts**:
   - Outputs will be saved in the `outputs/` folder after training.

## Results
- Current outputs are noisy (see `outputs/`), lacking clear urban features.
- California dataset shows slight diversity compared to Gurugram due to structured layouts.
